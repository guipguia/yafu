# Security Policy

## Supported Versions

Currently, the project is under active development. The latest commit to the main branch is considered the supported version for security updates. 

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |

## Reporting a Vulnerability

We take security seriously. If you discover a security vulnerability within YAFU, please send an e-mail to **guilherme@pguia.com**. 

Please do **not** use the public issue tracker for reporting security vulnerabilities.

We will try to acknowledge your report within 48 hours and we will work with you to resolve the issue as quickly as possible.
